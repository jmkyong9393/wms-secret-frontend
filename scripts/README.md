# scripts

리포 루트에 흩어져 있던 일회성 스크립트와 실험 자료를 모아 둔 곳입니다.
**애플리케이션 빌드·실행 경로에 포함되지 않습니다.**

## codemod/

이미 적용이 끝난 일회성 치환 스크립트입니다. **다시 실행하지 마십시오** —
대상 코드가 이미 바뀌어 있어 의도한 치환이 일어나지 않습니다.

| 파일 | 무엇을 바꿨나 |
| --- | --- |
| `patch_cert.py` | 공개 보증서 화면(`certificate/[lpn]`)의 하드코딩 결함 문구를 실제 판정 결과(`agent_logs`) 참조로 교체 |
| `patch_ui.py` | 재고 상세 화면(`admin/inventory/[id]`)의 동일 문제 교체 |

보관 이유는 "무엇을 왜 걷어냈는가"의 근거가 되기 때문입니다. 삭제하면 하드코딩된
가짜 판정 문구가 있었다는 사실과 그 교체 범위를 추적할 수 없습니다.

## scraping/

ISBN 도서 메타데이터 조회의 셀렉터를 확인하려고 만든 탐색용 자료입니다.
현재 애플리케이션 소스에서 참조하지 않습니다 — 메타데이터 조회는 백엔드가 담당합니다.

| 파일 | 내용 |
| --- | --- |
| `test_yes24.js` | 검색 결과에서 도서명을 뽑는 셀렉터 확인용 한 줄 스크립트 |
| `fixtures/yes24_search.html` | 검색 결과 페이지 저장본 (오프라인 셀렉터 검증용) |
| `fixtures/yes24_product.html` | 상품 상세 페이지 저장본 |

셀렉터가 깨졌을 때 네트워크 없이 재확인하는 용도로 남겨 둡니다.
